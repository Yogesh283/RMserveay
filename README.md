# Match IQ

Match IQ monorepo: React Native (Expo) UI, Unity game, FastAPI backend, and admin panel.

## Structure

- `MatchIQ_App` – Expo / React Native mobile UI
- `Unity_Game` – Unity Mahjong / tournament game
- `Backend` – FastAPI API
- `AdminPanel` – Admin dashboard
- `Database` – SQL / migrations
- `Documentation` – Project docs
- `Nakama` – Multiplayer server config
- `Deployment` – Deploy scripts / configs
- `MatchIQ_Flutter` – Legacy Flutter experiments

## Notes

Secrets (`.env`, keystores) are not included. Use `.env.example` files where present.
